# Product Draft

Сервис для подготовки черновиков карточек измерительных приборов.
Стек: Python, FastAPI, Pydantic, Qwen3 8B через локальный API Ollama.

## Запуск

Нужны Python 3.11+ и [Ollama](https://ollama.com/download).
Команды для PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
ollama pull qwen3:8b
python -m uvicorn app.main:app --reload
```

Ollama должна работать в фоне. При необходимости запустите `ollama serve`
в отдельном терминале. API-ключ не нужен.

Откройте http://127.0.0.1:8000/docs → `POST /generate` → `Try it out`.
Вставьте JSON из `examples/manometer.json` и нажмите `Execute`.
Обязательно только непустое `name`; неизвестные характеристики передавайте
как `null` или пустую строку.

В ответе: заголовок до 70 символов, описание на 800–1200 символов,
характеристики, 3–5 поисковых запросов, блок для менеджера и список пропусков.

## Как работает

1. Pydantic проверяет входной JSON и очищает пустые поля.
2. Сервис отправляет данные и промпт из `app/prompts.py` в Ollama.
3. Модель пишет текст и выбирает цитату о назначении из исходного описания.
4. Сервис проверяет формат, длину, уникальность запросов, отсутствие новых
   чисел, неподтверждённых обозначений стандартов и наличие цитаты в источнике. При ошибке даёт одну попытку исправления.
5. Характеристики копируются из входа; пустые значения заменяются на «данных нет».
   Коммерческий блок собирается по проверенной цитате, без догадок об отраслях.

Некорректный вход возвращает 422, ошибка ответа модели — 502,
недоступная Ollama — 503, таймаут — 504.

Настройки задаются переменными окружения: `OLLAMA_URL`, `OLLAMA_MODEL`,
`OLLAMA_TIMEOUT`. По умолчанию: `http://127.0.0.1:11434`, `qwen3:8b`, 180 секунд
на одну попытку. `.env.example` — образец; сам файл `.env` не загружается.

## Примеры и тесты

В `examples` лежат входы, результаты `*.result.json` и читаемая версия
`cards.md`. Сохранённые тексты вычитаны после генерации: убраны повторы и
неподтверждённые формулировки. Повторный запуск скрипта перезапишет примеры
ответами модели без редакторской правки. Манометр взят из примера задания; термометр T-demo вымышленный,
поскольку отдельные данные второго товара не были предоставлены.

```powershell
python -m pytest -q
python generate_examples.py
```

Автотесты используют заглушку модели и не требуют Ollama. Скрипт примеров
вызывает обработчик FastAPI через TestClient и обращается к настоящей модели.
Проверено: 25 тестов прошли. Примеры получены через локальную Qwen3 8B.
